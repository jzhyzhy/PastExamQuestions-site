# PastExamQuestions-site

Public VCE study website generated from a separate local/Gitea master repository.

https://jzhyzhy.github.io/PastExamQuestions-site/

This repository contains only published pages and resources. Edit the master data, then regenerate this site; do not edit generated files here.

## Analytics

Visitor stats use Cloudflare Web Analytics. The beacon is injected at the edge by
Cloudflare, so this repository contains no analytics code and none should be added.
Architecture, DNS records and how to verify it: [`docs/analytics.md`](docs/analytics.md).
